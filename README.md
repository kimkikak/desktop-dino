# DeskPet

## 주요 기능

* **기본 행동**

  * 걷기, 뛰기, 잠자기, 포효 등의 행동을 수행합니다.
  * 잠든 공룡은 일정 시간이 지난 후 깨거나, 여러번 좌클릭하여 깨울 수 있습니다.

* **공룡 상호작용**

  * 공룡을 클릭하여 잡을 수 있습니다.(잘때, 뛸때, 밥 먹을때, 쓰다듬을때는 잡을 수 없습니다.)
  * 우클릭 메뉴를 통해 원하는 행동을 선택할 수 있습니다.
    - 마우스를 움직이거나 클릭하여 공룡을 쓰다듬을 수 있습니다.
    - 밥을 줄 수 있습니다.
    - 노트북을 사용할 수 있습니다.

* **설정**

  * 공룡의 크기를 조절할 수 있습니다.
  * 앱을 종료할 수 있습니다.
  * 공룡 색을 설정할 수 있습니다.

## macOS 실행 안내

DeskPet은 Apple 개발자 서명이 되어 있지 않아서, macOS Gatekeeper가 다운로드한 앱에 자동으로 격리(quarantine) 속성을 붙입니다. 이 때문에 `.dmg`에서 앱을 설치한 뒤 그냥 실행하면 "파일이 손상되었습니다" 오류가 뜨며 실행되지 않습니다.

터미널에서 아래 명령어를 실행한 뒤 앱을 열어주세요.

```sh
sudo xattr -cr /Applications/DeskPet.app
open /Applications/DeskPet.app
```
